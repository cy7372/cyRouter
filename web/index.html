监听端口
修改后需重启服务生效。安装版默认 20108，开发版默认 20100。
从其他实例克隆配置
从另一台运行中的 cyRouter 拉取供应商/模型配置（先预览差异再确认；API key 以明文传输后用本机密钥重新加密）。本机端口、代理、cyRouter 密钥不受影响。典型用途：发布版（20108）从开发版（20100）同步配置。
全局代理
国际供应商（如 OpenCode Go）出网代理地址。留空 = 不使用代理（国内直连）。修改后立即生效。
密钥脱敏
自动检测请求中疑似 API Key（sk-/AIza/hf_/ghp_ 等已知前缀 + 32位以上高熵串），替换为占位符后转发供应商，响应返回时再还原。防止 Prompt/代码中粘贴的密钥泄露，对客户端透明。
显示实际开销
Token 统计是否显示实付金额（即扣掉套餐/缓存折扣后的开销 ¥理论总价(¥实付)）。 关闭后只显示理论总价。实际计费不受影响，仅控制显示。
